# iceNotePad

โปรแกรม Notepad สไตล์ Windows ที่ออกแบบมาสำหรับ **MacBook Apple Silicon (M1/M2/M3)** โดยเฉพาะ
เขียนด้วย **Swift & SwiftUI/AppKit** เป็น Native Binary (arm64) ที่เปิดทำงานได้ทันที เสี้ยววินาที และกินแรมน้อยมาก

## จุดเด่นและฟังก์ชันการทำงาน

1. **ล้างฟอร์แมตอัตโนมัติ (Strict Plain-Text)**:
   - ก๊อปปี้ข้อความจากเว็บ, Word, หรือแอปใดๆ มาวาง ระบบจะลบสี ขนาดฟอนต์ ตาราง ลิงก์ และสไตล์ทิ้งทั้งหมด เหลือเฉพาะตัวอักษรดิบๆ ทันที
2. **ระบบหลาย Tabs (Multi-Tab)**:
   - รองรับการเปิดหลายเอกสารพร้อมกันในหน้าต่างเดียว
   - มีปุ่ม `+` เพิ่มแท็บใหม่ และปุ่ม `✕` ปิดแท็บ
3. **Session Persistence (จำแท็บและข้อความเดิมข้ามการเปิด-ปิด)**:
   - หากไม่ปิดแท็บ เมื่อปิดโปรแกรม (Quit) หรือรีสตาร์ทเครื่อง แล้วเปิด `iceNotePad` ขึ้นมาใหม่ ทุกแท็บพร้อมข้อความที่ยังไม่ได้เซฟจะกลับมาอยู่ครบเหมือนเดิมอัตโนมัติ
4. **ความรู้สึกและฟีเจอร์เหมือน Windows Notepad**:
   - Status Bar ด้านล่าง: บอกตำแหน่งบรรทัด/คอลัมน์ (`Ln, Col`), จำนวนตัวอักษร, Zoom %, รูปแบบขึ้นบรรทัดใหม่ (`CRLF` / `LF`), และ `UTF-8`
   - ค้นหาและแทนที่คำ (`Find & Replace`): กด `Cmd + F` พร้อมปุ่มนับจำนวนคำที่ค้นพบ
   - ซูมขยายตัวอักษร: `Cmd + +` (Zoom In), `Cmd + -` (Zoom Out), `Cmd + 0` (Reset)
   - เปิดไฟล์ (`Cmd + O`), บันทึกไฟล์ (`Cmd + S`), Save As (`Cmd + Shift + S`)

## คีย์ลัด (Shortcuts)

| ฟังก์ชัน | คีย์ลัด |
|---|---|
| สร้าง Tab ใหม่ | `Cmd + T` หรือ `Cmd + N` |
| ปิด Tab ปัจจุบัน | `Cmd + W` |
| สลับไปยัง Tab ถัดไป | `Cmd + Shift + ]` |
| สลับไปยัง Tab ก่อนหน้า | `Cmd + Shift + [` |
| สลับไปยัง Tab ที่ 1 - 9 | `Cmd + 1` ถึง `Cmd + 9` |
| ค้นหา / แทนที่ (Find & Replace) | `Cmd + F` (กด `Esc` เพื่อปิด) |
| ขยาย / ย่อ ขนาดตัวหนังสือ | `Cmd + +` / `Cmd + -` / `Cmd + 0` |
| บันทึกไฟล์ | `Cmd + S` |
| บันทึกเป็น (Save As) | `Cmd + Shift + S` |
| เปิดไฟล์ | `Cmd + O` |

## วิธีติดตั้งและเริ่มใช้งาน

### 1. เปิดใช้งานทันที
เปิดจากโฟลเดอร์ build:
```bash
open build/iceNotePad.app
```

### 2. ติดตั้งเข้าโฟลเดอร์ Applications ของ Mac (แนะนำ)
รันคำสั่งนี้เพียงครั้งเดียว เพื่อให้เปิดผ่าน Spotlight (`Cmd + Space` แล้วพิมพ์ `iceNotePad`) หรือกดจาก Launchpad ได้ทันที:
```bash
cp -r build/iceNotePad.app /Applications/
```

### 3. หากต้องการ Build ใหม่ในอนาคต
```bash
./scripts/build_app.sh
```
