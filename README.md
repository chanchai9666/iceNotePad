# iceNotePad

โปรแกรม Notepad สไตล์ Windows ที่ออกแบบมาสำหรับ **MacBook Apple Silicon (M1/M2/M3/M4)** โดยเฉพาะ
เขียนด้วย **Swift & SwiftUI/AppKit** เป็น Native Binary (arm64) ที่เปิดทำงานได้ทันที เสี้ยววินาที ไร้ Bloatware และกินทรัพยากรน้อยเป็นพิเศษ

---

## จุดเด่นและฟังก์ชันการทำงาน

1. **ล้างฟอร์แมตอัตโนมัติ (Strict Plain-Text)**:
   - ก๊อปปี้ข้อความจากเว็บ, Word, หรือแอปใดๆ มาวาง ระบบจะลบสี ขนาดฟอนต์ ตาราง ลิงก์ และสไตล์ทิ้งทั้งหมด เหลือเฉพาะตัวอักษรดิบๆ ทันที
2. **ระบบจัดการแท็บเต็มรูปแบบ (Multi-Tab & Context Menu)**:
   - รองรับการเปิดหลายเอกสารพร้อมกันในหน้าต่างเดียว
   - มีปุ่ม `+` เพิ่มแท็บใหม่ และปุ่ม `✕` ปิดแท็บ
   - **ดับเบิลคลิกบนแถบแท็บ**: ดับเบิลคลิกพื้นที่ว่างบนแถบแท็บเพื่อเปิดแท็บใหม่ทันที
   - **Context Menu บนแท็บ** (คลิกขวา):
     - **เปลี่ยนชื่อไฟล์ (Rename File...)**: เปลี่ยนชื่อแท็บและเปลี่ยนชื่อไฟล์จริงบน Disk พร้อมตรวจสอบการชนกันของชื่อไฟล์
     - **ทำซ้ำแท็บ (Duplicate Tab)**: คัดลอกเอกสารและ Encoding ปัจจุบันออกเป็นแท็บใหม่ได้ทันที
     - **ปิดแท็บ (Close Tab)**
3. **Session State Persistence (จำแท็บและข้อความเดิมข้ามการเปิด-ปิด)**:
   - หากไม่ปิดแท็บ เมื่อปิดโปรแกรม (Quit) หรือรีสตาร์ทเครื่อง แล้วเปิด `iceNotePad` ขึ้นมาใหม่ ทุกแท็บพร้อมข้อความที่ยังไม่ได้เซฟจะกลับมาอยู่ครบเหมือนเดิมอัตโนมัติ พร้อมระบบ Backward Compatibility รองรับการอัปเกรดเวอร์ชัน
4. **ความรู้สึกและฟีเจอร์เหมือน Windows Notepad**:
   - **Status Bar ด้านล่าง**: บอกตำแหน่งบรรทัด/คอลัมน์ (`Ln, Col`), จำนวนตัวอักษร, Zoom %, รูปแบบขึ้นบรรทัดใหม่ (`Windows (CRLF)` / `Unix (LF)`), และ Encoding จริงของเอกสาร (`UTF-8`, `Western (ISO Latin 1)`)
   - **ระบบค้นหาและแทนที่คำ (Find & Replace)**:
     - กด `Cmd + F` เปิดแถบค้นหาพร้อม Focus ที่ช่องพิมพ์ทันที
     - กด `Enter` ในช่องค้นหาเพื่อค้นหาและเลื่อนไปยังผลลัพธ์ถัดไปเรื่อยๆ อย่างต่อเนื่อง
     - ปุ่มลูกศร **Previous / Next** (`Cmd + Shift + G` / `Cmd + G`) พร้อมไฮไลต์ตำแหน่งคำบน Editor ด้วย Native Find Indicator
     - แสดงลำดับคำที่พบ (`Match X of Y`) และตัวเลือกแยกแยะตัวพิมพ์เล็ก-ใหญ่ (`Match Case`)
     - แทนที่คำ (`Replace`) และแทนที่ทั้งหมด (`Replace All`)
   - **ซูมขยายตัวอักษร**: `Cmd + +` (Zoom In), `Cmd + -` (Zoom Out), `Cmd + 0` (Reset)
   - **การจัดการไฟล์**: เปิดไฟล์ (`Cmd + O`), บันทึกไฟล์ (`Cmd + S`), Save As (`Cmd + Shift + S`)
   - **ปิดแท็บและหน้าต่าง**: `Cmd + W` ปิดแท็บปัจจุบัน และจะปิดหน้าต่างอัตโนมัติหากปิดแท็บสุดท้าย

## คีย์ลัด (Keyboard Shortcuts)

| ฟังก์ชัน | คีย์ลัด |
|---|---|
| สร้าง Tab ใหม่ | `Cmd + T` หรือ `Cmd + N` |
| ดับเบิลคลิกพื้นที่ว่างบน Tab Bar | สร้าง Tab ใหม่ |
| ปิด Tab ปัจจุบัน (ปิดหน้าต่างเมื่อเหลือแท็บสุดท้าย) | `Cmd + W` |
| สลับไปยัง Tab ถัดไป | `Cmd + Shift + ]` |
| สลับไปยัง Tab ก่อนหน้า | `Cmd + Shift + [` |
| สลับไปยัง Tab ที่ 1 - 9 | `Cmd + 1` ถึง `Cmd + 9` |
| ค้นหา / แทนที่ (Find & Replace) | `Cmd + F` (Focus ทันที, กด `Esc` เพื่อปิด) |
| ค้นหาคำถัดไป (Next Match) | `Enter` (ในช่อง Find) หรือ `Cmd + G` |
| ค้นหาคำก่อนหน้า (Previous Match) | `Cmd + Shift + G` |
| ขยาย / ย่อ ขนาดตัวหนังสือ | `Cmd + +` / `Cmd + -` / `Cmd + 0` |
| บันทึกไฟล์ (Save) | `Cmd + S` |
| บันทึกเป็น (Save As) | `Cmd + Shift + S` |
| เปิดไฟล์ (Open) | `Cmd + O` |

## วิธีติดตั้งและเริ่มใช้งาน

### วิธีที่ 1: ติดตั้งผ่าน GitHub Release (แนะนำสำหรับผู้ใช้งานทั่วไป)
1. ไปที่เมนู **[Releases](https://github.com/chanchai9666/iceNotePad/releases)** ทางแถบขวามือของ GitHub
2. ดาวน์โหลดไฟล์ **`iceNotePad.dmg`** หรือ **`iceNotePad.zip`**
3. ดับเบิ้ลคลิกเปิดไฟล์ แล้วลากไอคอน **`iceNotePad`** ไปใส่ในโฟลเดอร์ **`Applications`** ของเครื่อง Mac
4. ดับเบิ้ลคลิกเปิดใช้งานโปรแกรมได้ทันที

---

### วิธีที่ 2: คอมไพล์จาก Source Code
1. Clone หรือดาวน์โหลด ZIP จาก GitHub:
   ```bash
   git clone https://github.com/chanchai9666/iceNotePad.git
   cd iceNotePad
   ```
2. รันสคริปต์คอมไพล์เพื่อสร้าง App Bundle:
   ```bash
   ./scripts/build_app.sh
   ```
3. แอปจะถูกสร้างไว้ที่ `build/iceNotePad.app` สามารถลากไปใส่โฟลเดอร์ `/Applications` ได้ทันที

---

### ⚠️ ข้อควรรู้เมื่อเปิดแอปครั้งแรก (macOS Gatekeeper)
เนื่องจากแอปนี้เป็นโอเพนซอร์สที่ไม่ได้ลงทะเบียนเสียค่าบริการกับ Apple Developer ($99/ปี) ในการเปิดครั้งแรก macOS อาจแสดงข้อความเตือนความปลอดภัย:
> *"iceNotePad can't be opened because Apple cannot check it for malicious software"*

**วิธีเปิดใช้งานง่ายๆ (ทำเพียงครั้งแรกครั้งเดียว):**
1. **คลิกขวา** (หรือกดปุ่ม `Control` ค้างไว้แล้วคลิก) ที่ไอคอน **`iceNotePad`**
2. เลือกเมนู **Open (เปิด)**
3. ในหน้าต่างที่เด้งขึ้นมา ให้กดปุ่ม **Open (เปิด)** อีกครั้ง โปรแกรมจะเปิดขึ้นมาและจำไว้ ทำให้ครั้งต่อไปสามารถดับเบิ้ลคลิกเปิดได้ตามปกติทันที

*(หรือไปที่ **System Settings** > **Privacy & Security** เลื่อนลงมาล่างสุดแล้วกด **"Open Anyway"**)*
